# piano-melody-web

Browser piano keyboard — play melodies with mouse or keyboard in vanilla JavaScript.

## The problem

You want to learn Web Audio API and keyboard events through something more fun than another form validator.

## What it does

Interactive piano in `index.html`, `script.js`, and `style.css` — click keys to play notes.

## Install

```bash
git clone https://github.com/irachrist1/piano-melody-web.git && cd piano-melody-web
open index.html
```

## How it works

- **Web Audio oscillators or samples.** Each key triggers a sound — browser-native audio without plugins.
- **Keyboard + mouse input.** Dual input paths — event handling practice with immediate feedback.
- **CSS key layout.** Piano keys styled and positioned — visual + audio in one small project.
